● Diseño técnico

Arquitectura del sistema

🏗️
Estructura general

  • Sitio estático puro — sin framework, sin build step
  • 12 HTML independientes + assets/shared.css + assets/shared.js
  • Cada página incluye su CSS scope en <style> inline
  • JavaScript embebido en cada página para data y lógica local
  • index.html redirige automáticamente a inicio.html

🎨
Sistema de diseño (shared.css)

  • CSS custom properties en :root para tema oscuro
  • 8 colores de acento configurables vía data-accent
  • --accent, --bg, --surface, --line, --text-dim
  • Grid y Flexbox nativos — sin Bootstrap ni utilidades externas
  • Backdrop-filter para efectos glass en nav y filtros sticky
  • Google Fonts: Fraunces, Inter, JetBrains Mono, Anton, Instrument Serif

🌐
Internacionalización (i18n)

  • Bilingüe ES/EN sin librería externa
  • Atributos data-i18n-es y data-i18n-en en cada nodo de texto
  • M26.getLang() y M26.setLang() en shared.js
  • Toggle en navbar — persiste en localStorage
  • Datos de jugadores y curiosidades: objetos { es, en }

🖼️
Gestión de imágenes

  • loading="lazy" en todas las imágenes y videos
  • Patrón position:absolute; inset:0 para cobertura total
  • object-fit:contain + padding para kits/badges de equipos
  • object-fit:cover + luminosity blend para fotos históricas
  • onerror silencia assets faltantes sin romper la UI
  • WebP preferido para fotos (goleadores, insignias, selecciones, historia)

🎬
Videos embebidos

  • Iframes YouTube con loading="lazy"
  • Contenedor aspect-ratio:16/9 + iframe position:absolute;inset:0
  • 20+ momentos en momentos.html con lazy rendering
  • 3 goles históricos en revelaciones.html con etiquetas overlay
  • allow="autoplay; fullscreen" habilitado

⚡
Interactividad JS

  • Filtros sticky por confederación, década, era — sin recarga de página
  • Lightbox modal para selecciones y jugadores (ESC para cerrar)
  • Renderizado dinámico con arrays de datos en cada página
  • Delegación de eventos en document.addEventListener("click")
  • Template literals con string concatenation para evitar XSS en anidación
